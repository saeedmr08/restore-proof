# Security

RestoreProof is a **synthetic DR rehearsal tool**. It does not read, write, restore, or delete any real backups, volumes, snapshots, or databases.

## Boundaries

- All plans, systems, and measurements are demo fixtures.
- Checklist state lives in the browser session only.
- No cloud credentials or infrastructure APIs are used.

## Safe use

- Do not point this UI at production inventory.
- Treat scored results as training artifacts, not compliance evidence for live systems.
